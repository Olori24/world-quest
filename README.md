# WORLD QUEST

Mobile-first global adventure game prototype.

## Run locally
Open `index.html` in a modern browser. No build step required.

## Included
- Responsive adventure dashboard
- Mission completion and local reward/XP progression
- Leveling and reputation display
- Destination selection for Lagos, Abuja, Benin City, and Osogbo

## Current prototype limitations
- Progress is in-memory and resets on refresh.
- Coins are fictional in-game points; no deposits, withdrawals, payments, or real-money earning.
- Supabase persistence, authentication, server-side reward validation, multiplayer, and production deployment are not connected in this starter.

This is a playable frontend scaffold, not the previously discussed full production game.
